<b>Role</b> Technical and Managerial Team Lead. <br/><b>Technologies/Tools</b> J2EE, Struts, Hibernate, XML, OracleJdeveloper10g. <br/><b>Description</b> Designing and implementing with a team of 4 members the NSGB admin web tool. The tool consists of 4 modules. <li> Subscription module is responsible for the subscriptions of a customer to some products or services. <li> Administration module is responsible for maintaining the user profile that uses the system. <li> Reporting module is responsible for generating reports for all channels and these reports could be exported to excel sheets and PDF. <li> Security module assigns the roles and the privileges for the users. <br/> <i> Raya Software. Jul 2005 – Jan 2008 </i>.
